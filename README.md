# Borneo × Intatto (Solana)

Shopping agents that pay with your tokenized stocks without selling them, and never touch the money.

- **Borneo** controls *what* an agent buys: real merchant catalogs and a locked quote the agent cannot alter.
- **Intatto** controls *how* it pays: stock-backed credit whose borrow limit tracks the US market session.

Work in progress for the Colosseum Crypto World's Fair hackathon.
